# MacroZone

A modern React Native nutrition and macro tracking app built with Expo.

Track meals, monitor macros, and share your nutrition data with a clean mobile-first experience.

---

## Features

- Meal tracking
- Macro calculations
- Share meals
- Clean and responsive UI
- Built with Expo Router
- Cross-platform support (Android & iOS)

---

## Tech Stack

- React Native
- Expo
- Expo Router
- TypeScript
- React Hooks

## Installation

Clone the repository:

```bash
git clone https://github.com/Nabeel002/macrozone.git
```

Go into the project:

```bash
cd macrozone
```

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

---

## Running on Device

### Android

- Install Expo Go
- Scan the QR code from terminal/browser

### iOS

- Install Expo Go from App Store
- Scan the QR code using Camera app
